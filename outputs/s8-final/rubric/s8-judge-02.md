# Rubric scoring — s8-judge-02

### I-1019 — Private Elder Statement Scanner
Direct-adjacent fraud monitors (Carefull, EverSafe, StatementLock) already exist; on-device Gemini Nano angle is the main differentiator, not the category.

### I-1050 — Built on Jev
Barely a product: no defined buyer, no business model, and depends entirely on an external model's unverified speed claims and existing wrapper tools.

### I-1516 — Console-Checked Cyber Insurance Answers
Compliance-questionnaire agents (Anchor AI, Conveyor, CyberQP) already exist, but live console verification via Claude for Chrome is a real, timely, demoable differentiator.

### I-1555 — Same Words, More Life
Filler removal and voice restyling are mature categories (Cleanvoice, Descript, ElevenLabs); the expressive-restyle-in-sync-with-slides angle is incremental.

### I-2043 — Client Quote Estimator for Dev Shops
Estimation tools already exist (Devtimate, Scope); repo-reading coding-agent grounding is a real improvement but a thin, easily copied wrapper.

### I-2061 — Grounded Notes With Timestamp Citations
Local scribes exist, but claim-level timestamp traceability directly attacks the fabrication problem competitors ignore — strong niche differentiation and daily pain.

### I-2514 — E&O Broker's Citation Shield
Citation checkers exist (Clearbrief, CaseRead, LawDroid) but the broker-bundled, on-prem, aggregate-risk-score distribution model is a genuinely different go-to-market.

### I-2536 — AI PC optimiser and fixer
Microsoft is shipping an agentic Fix-it button into Windows itself — a near-fatal direct competitor with a free, bundled, first-party alternative.

### I-3026 — Redaction Relay
PII-redaction-before-cloud is already a category (RedactLocal, Redacta, Justee); little differentiation beyond local model choice and reinsertion mechanic.

### I-3046 — Lay of the Land
Farm-mapping apps exist (Farmable, Mobble) but none capture retiring-owner narrated memory with confidence-tagged provenance — a genuinely fresh, emotionally resonant angle.

### I-3088 — Vendor Hold-Queue Call Agent
Hold-skipping tools exist broadly (Hold for Me, DoNotPay) but verticalizing into vendor support with fix-verification against real system state is a real niche twist.

### I-3537 — Supply-Run Spend Guardrail
AgentPay is a direct competitor already solving agent payment caps; session-level (vs per-call) budgeting is a narrow, likely-copyable wedge in a still-tiny market.

### I-4005 — POA Packet Builder
Generic form-fillers exist (DocFills, OCR-Software) but none target bank-specific POA certification plus a statute-citing rebuttal letter — sharp, painful, well-evidenced niche.

### I-4501 — Screen Agent Drafts Session Notes
Scribes exist (Freed, Upheal) but none use a GUI-grounding agent to type into API-less legacy EHRs — a genuinely novel, high-wow mechanism.

### I-4546 — 72-Hour Appeal Sprint
Appeal-filing startups exist (Claimable, Counterforce, Aegis) but the OCR-to-portal-submission-to-confirmed-filing-ID pipeline in a 72-hour crisis window is a sharp, high-stakes, well-priced wedge.

### I-5109 — Live Interpreter With Transcript
Medical AI interpreters are a crowded direct-competitor space (Mabel, GoSpeech, Aida); the two-language transcript-as-evidence angle is a modest add, not a new category.

### I-5410 — Micro-Seller Customs Declaration Autopilot
Customs/classification tools already exist (Zonos, Easyship, Tarifflo) as direct competitors, though the de-minimis-ending trigger gives strong urgency and timing.

### I-6006 — AAC Phrase Ranking Companion
Adjacent AAC prediction tools exist but a device-agnostic companion that only ranks the user's own vetted phrases (never composes) is a distinct, trust-preserving niche.
