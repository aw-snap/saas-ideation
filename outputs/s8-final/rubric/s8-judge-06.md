# Rubric scoring — s8-judge-06

### I-1022 — Rejection-Proof Renewal Filer
Rule-based rejection checker for Medicaid/Medicare filings. Adjacent Medicaid navigators exist but not this pre-submit checklist niche; easy build, thin moat.

### I-1063 — Rate-Con Learned From One Build
One-example rate-confirmation drafting for freight brokers. Several TMS automation competitors already do document generation; real daily pain, easy to copy.

### I-1516 — Console-Checked Cyber Insurance Answers
Claude-for-Chrome verifies control answers live across admin consoles before insurance submission. Strong recency, high pain, good live demo, moderate moat.

### I-1564 — Draft From Case Files, Offline
Fully offline case-file drafting via gpt-oss-20b. A near-identical open-source local-legal-ai project exists; real pain and clean wifi-off demo.

### I-2045 — Same Words, More Life
Voice-preserving re-speak with forced-alignment timing to fix monotone lectures. Genuinely differentiated from filler-removal tools but riskiest to actually pull off cleanly.

### I-2061 — Grounded Notes With Timestamp Citations
On-device SOAP notes citing exact transcript timestamps for every claim. Several local scribe tools exist, but hallucination-grounding is a real differentiator and daily pain.

### I-2519 — The Compliance Portal Copilot
Local WISP drafting plus browser-agent filing across PTIN/insurer portals. WISP generators already exist; filing/tracking layer adds some novelty, narrow annual pain.

### I-2547 — Multi-Institution Proxy Agent
Weekly digest across a parent's portals via browser agent. Carefull already targets this caregiver-monitoring niche closely; strong pain, easy demo, thin moat.

### I-3026 — Redaction Relay
Local PII redaction/reinsertion around cloud LLM calls for lawyers/CPAs. Flagged direct competitors (RedactLocal, Redacta, Justee) do the same mechanism already.

### I-3048 — Remote Family PC Copilot
Evidence-based PC diagnosis with remote family approval. Crowded diagnostic-tool space (PC Doctor, Quick Assist); solid demo, easy build, modest pain.

### I-3093 — Privileged Cite Bench
Fully offline citation verification against cached case law for litigators. Existing cite-checkers are cloud-only, so offline/privilege angle is a real, demoable differentiator.

### I-3537 — Supply-Run Spend Guardrail
Session-wide spend cap across an agent's multi-site shopping run. Flagged direct competitor AgentPay already builds this exact session-budget mechanism.

### I-4014 — Pivot: Will the Sofa Fit?
Phone video to 3D route reconstruction with a fit verdict and maneuvering animation. Existing calculators/scanners are adjacent, not equivalent; high-wow but hardest build.

### I-4511 — Proof Receipts for Proxy Agents
Screenshot-to-redacted-receipt proof for agent proxy actions. Meridian Verity already brands itself around "AI agent verification receipts," closely overlapping the core mechanism.

### I-4546 — 72-Hour Appeal Sprint
OCR denial letter, draft appeal, file and confirm inside a Medicare Advantage portal within the expedited window. Crowded appeal-startup space but specific, high-pain, high-wow workflow.

### I-5203 — Scope Gate for Your Own Agent
Local mandate/scope enforcement gate before agent actions execute. Overlaps closely with existing Mandate/AP2/Permit.io pre-action authorization concepts; low novelty.

### I-6001 — Continuous authorised social-engineering testing
Weekly AI-driven vishing/phishing tests against staff and now AI agents, with auto-retest. Adjacent red-team vendors exist; extending targets to AI agents is the fresh angle.

### I-6006 — AAC Phrase Ranking Companion
Device-agnostic companion that ranks an AAC user's own imported phrases live from conversation. Distinct from in-device word-prediction incumbents; real daily communication pain, buildable demo.
