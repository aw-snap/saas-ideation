# Gate D loop 1: web verification of the `[unverified]` prior-art claims

Gate D has no web tools, so the primary session checked its five unverified competitor claims with one search each on 2026-09-26. Each entry gives what the source says and the effect on the idea. None of these changes a knock-out: each product differs from the idea in niche or mechanism, as noted.

| Gate D claim | Result | Source | Effect |
|---|---|---|---|
| Abridge "Linked Evidence" links note sentences to the transcript (I-2061) | **Verified.** Abridge's support documentation says each sentence in the generated note links back to the transcript excerpt and audio timestamp it came from, and the clinician can replay the audio. | [Abridge support: Verify a Note With Linked Evidence](https://support.abridge.com/hc/en-us/articles/30235128433811-Verify-a-Note-With-Linked-Evidence) | I-2061 stays adjacent. Abridge is a cloud scribe for health systems and physicians. The per-sentence citation UI is not new, so I-2061's claim narrows to on-device drafting for solo therapists, with untraceable sentences flagged. |
| ShieldsOn does real-time grandparent-scam detection with family alerts (I-2067) | **Verified that it exists.** ShieldsOn describes AI real-time scam detection for robocalls, impersonators and urgent-demand scams, with one tap to block and one tap to alert family. Its site does not say whether it runs on-device. | [shieldson.ai](https://shieldson.ai/) | Borderline for I-2067: the same buyer and a close mechanism. It stays adjacent only on its on-device processing and its check against the family's own known facts. The report should call it the closest competitor. |
| KnowBe4 / Hoxhunt own staff phishing and vishing simulation (I-6001) | **Verified for Hoxhunt.** Hoxhunt unifies phishing, smishing, vishing and AI-driven impersonation, including deepfake audio and video in simulated attacks. | [Hoxhunt: deepfake phishing attack](https://hoxhunt.com/feature/deepfake-phishing-attack) | For I-6001, the staff-testing half is covered by incumbents, and the AI-agent half by Lakera Red and Mindgard (named in S5). Its novelty is only the bundle of the two with fix-and-retest. |
| USPS Informed Delivery emails daily images of incoming mail (I-2550) | **Verified.** A free daily email carries grayscale images of the address side of up to 10 incoming letter-mail pieces. | [USPS FAQ: Informed Delivery, the basics](https://faq.usps.com/s/article/Informed-Delivery-The-Basics) | For I-2550 this is an ingestion channel, not a competitor: it shows envelopes only and does not detect renewal packets or read deadlines. It answers the red team's objection that the parent must photograph their own mail. |
| Infinitus runs AI voice agents on payer calls for prior authorization (I-1534) | **Verified.** Infinitus voice AI agents call payers on behalf of providers to follow up on prior authorizations. | [Infinitus: prior authorization](https://www.infinitus.ai/solutions/prior-authorization/) | I-1534 stays adjacent. Infinitus places automated calls, while I-1534 transcribes the clinician's own live peer-to-peer call into a quote-cited case file. |
