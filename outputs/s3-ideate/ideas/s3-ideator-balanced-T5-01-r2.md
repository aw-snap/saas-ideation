# The Advisor That Never Phones Home

One-liner (≤20 words): On-device agent finds security gaps on a solo practitioner's own laptop, using local diagnostics, no client file ever leaves.

Buyer and niche (≤25 words): Solo lawyers, therapists and accountants preparing cyber-insurance renewals or written security plans with no IT staff and confidential client files.

Pain and evidence (≤40 words): MFA gaps and stale risk analyses void cyber-insurance claims, yet solos "lack access to such advanced and costly infrastructure" to run AI locally themselves. (src: outputs/s3-ideate/pain/T5-dossier.md; outputs/s3-ideate/pain/T9-dossier.md)

How it works (≤50 words): A small open-weight model runs entirely on the practitioner's own machine, inspects real OS and account settings (MFA, encryption, patch status), shows evidence before flagging any gap, and drafts the cyber-insurance or WISP answer text, all without a specialist install or any client file touched.

Why now (≤25 words): gpt-oss-20b runs a capable reasoning model in 16GB RAM, letting solo practices get real local AI without a specialist install.

Demo moment (≤20 words): Laptop scan finds M365 MFA off; the agent drafts the exact questionnaire line and evidence screenshot live.

Business model (≤15 words): One-time license per machine, plus a low annual update fee.

# One Signed Form Per Vendor

One-liner (≤20 words): Tracks every AI vendor a solo tax preparer uses and keeps the required client consent current.

Buyer and niche (≤25 words): Solo CPAs, EAs and seasonal tax preparers who must get a separate signed consent for each AI vendor they use.

Pain and evidence (≤40 words): Pasting return data into personal AI without a standalone signed consent is a federal disclosure violation, fined up to $1,000 and a year in prison per instance, and a new consent is needed whenever the vendor changes. (src: outputs/s3-ideate/pain/T9-dossier.md)

How it works (≤50 words): The agent keeps a live inventory of every AI tool touching the practice's workflow, checks each against Rev. Proc. 2013-14's per-vendor consent wording, drafts the exact signed-consent form for each client relationship, and re-flags every client file the moment a vendor's terms or identity changes.

Why now (≤25 words): Cheap long-context models can watch vendor terms and this practitioner's own client list, then draft each mandated consent form automatically.

Demo moment (≤20 words): Swap in a new AI vendor; every affected client file flips to "consent needed" within seconds on screen.

Business model (≤15 words): Flat monthly fee per practice, billed like a malpractice-insurance add-on.

# The WISP That Writes Itself

One-liner (≤20 words): Builds a solo accountant's mandated written security plan by scanning their own consoles, never client return data.

Buyer and niche (≤25 words): Solo CPAs, EAs and tax preparers who must file a 15-20 page Written Information Security Plan every year.

Pain and evidence (≤40 words): Every e-filer must keep a WISP; fines start at $10,000 for preparers and $100,000 per violation under the FTC Safeguards Rule, yet a solo has no one to write it. (src: outputs/s3-ideate/pain/T9-dossier.md)

How it works (≤50 words): The agent logs into the preparer's own tax software, email, and cloud-storage admin panels, checks each Safeguards Rule control (encryption, access logs, vendor list, incident plan) against the practice's real settings, and drafts a dated WISP naming each control's actual state, never opening a client return itself.

Why now (≤25 words): Production browser agents now complete long multi-console admin walks reliably, the same skill payer-portal and insurance-questionnaire agents already use.

Demo moment (≤20 words): Three admin-panel logins later, a dated WISP appears citing the exact FTC Safeguards control it verified.

Business model (≤15 words): Annual fee per preparer, priced under one FTC Safeguards fine.

# Vet The Vendor Before The Client

One-liner (≤20 words): Checks an AI tool's data terms against your ethics rules before you paste in a single client file.

Buyer and niche (≤25 words): Solo lawyers and therapists deciding whether a new AI tool is safe for confidential client material, with no procurement team to ask.

Pain and evidence (≤40 words): Large firms have procurement and security teams negotiate data terms; solos "often cannot," yet must independently vet every vendor contract under ABA Op. 512's due-diligence duty. (src: outputs/s3-ideate/pain/T9-dossier.md)

How it works (≤50 words): Given a vendor's terms of service and privacy policy, the agent checks data retention, training-use opt-outs and subprocessor lists against the practitioner's bar or licensing-board rule, flags any clause that breaks confidentiality duties, and drafts the client-consent language the rule requires before the tool is used.

Why now (≤25 words): Long-context models read a full vendor contract and cross-check it against professional ethics rules in one pass, cheaply.

Demo moment (≤20 words): Paste a new AI tool's ToS; the agent flags the training-use clause and drafts the missing consent line.

Business model (≤15 words): Per-vendor review fee, or an unlimited monthly subscription for frequent evaluators.

# The Scribe's Access Ends On Time

One-liner (≤20 words): Sweeps every console a hired therapy scribe or virtual assistant touched the moment their contract ends.

Buyer and niche (≤25 words): Solo therapists and small law practices who hire virtual scribes or assistants for documentation and give them system access.

Pain and evidence (≤40 words): Therapist VAs "shift the confidentiality exposure rather than removing it," and separately, six in ten departing staff at small firms are never asked to return their cloud logins. (src: outputs/s3-ideate/pain/T9-dossier.md; outputs/s3-ideate/pain/T5-dossier.md)

How it works (≤50 words): When a scribe or VA's contract ends, the agent walks every console it was granted (notes platform, shared drive, scheduling tool, billing portal), revokes or rotates each credential, confirms no client file remains accessible, and produces a signed log proving the access is gone.

Why now (≤25 words): Browser agents now complete long multi-step console revocation workflows reliably, the same skill offboarding sweeps for larger firms already use.

Demo moment (≤20 words): Enter one departing VA's name; watch four separate console logins get revoked live on screen.

Business model (≤15 words): Per-offboarding fee, or bundled into a low monthly practice-security subscription.
