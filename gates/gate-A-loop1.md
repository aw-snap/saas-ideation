## Deliberate orchestrator choices

1. `args.skip` as complete output paths, not task ids: acceptable. Equivalent to the spec's intent, more robust (the task-to-file mapping lives in one place), and `pipe.py scan` produces it mechanically.
2. One ideator file per round: acceptable. Every file obeys the marker contract; a crashed round reruns alone; 8+5+5 = 18 cards satisfies the S3 done-when.
3. S8 rubric judges see the deep prior-art verdict line: acceptable and needed, since the Novelty anchor is "no analog after audit". The line carries verdict and competitor names only; no lineage, track or territory.
4. Pairing within a track: acceptable and required, since §11 makes Elo the primary ranking within each track.
5. Archive workers write part files, `pipe.py split` writes `archive/ideas` and `archive/blind`: acceptable. Keeps one writer per file (the primary) for `archive/`, and the blind copy strips frontmatter and `(src: ...)`. Needs A1 to be safe.
6. Script computes pairings/Elo, master writes verbatim: acceptable per §7, subject to A3.
7. 48-hour hackathon: recorded in the manifest and `config/context.md`; every agent body that judges buildability uses it consistently.
8. `pipe.py` between workflows: acceptable. All shuffles use `random.Random(run_seed)`; `assign()` is deterministic (selftest asserts it) and gives each territory's 4 ideators 4 distinct partners, never their own.
