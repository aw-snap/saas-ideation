# Constraint deck (S3 round 3)

Each ideator draws 2 constraints, assigned deterministically in `config/assignments.json`. An idea has to satisfy both of its constraints for real. Treating one as a footnote doesn't count.

- C01: The user never opens the app.
- C02: It operates legacy desktop software through computer use.
- C03: The customer is an AI agent.
- C04: Priced per outcome.
- C05: Runs fully on-device.
- C06: The only input is the phone camera.
- C07: The only interface is voice (a phone call or voice notes).
- C08: It lives inside a messaging app the user already has (WhatsApp, SMS, Slack or Teams).
- C09: The main output is a physical document or printout.
- C10: It keeps working offline for 8+ hours at a time.
- C11: The first useful result arrives within 60 seconds of signup.
- C12: Zero integration: it watches or drives the screen instead of calling an API.
- C13: Two parties who don't trust each other both rely on it.
- C14: It is sold to the buyer's accountant, broker or advisor, not the buyer.
- C15: Data never leaves the customer's building.
- C16: It works for someone who can't read well.
- C17: It runs once a year and still earns its price.
- C18: It replaces a form or government-portal submission end to end.
- C19: The product is an API with no UI at all.
- C20: Every output is verifiable against a source document.
- C21: It learns a task from a single demonstration by the user.
- C22: Built for a team of one.
- C23: Email is the only interface.
- C24: A human approves every irreversible action.
